# SeatFlow 🪑

A beautiful, modern seating planner for events. No sign-up. No backend.

## Quick Start (3 steps)

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# 3. Open in browser
open http://localhost:3000
```

## Features
- Drag & drop floor editor
- 8 prebuilt templates (wedding, gala, conference, classroom…)
- Auto Arrange smart seating
- Real PNG & PDF export (html2canvas + jsPDF)
- Mobile responsive with bottom sheet UI
- Save/load as .seatflow project files
- Guest groups with color coding
- No login, no backend, fully offline

## Export
- PNG → high-res canvas screenshot
- PDF → A4 landscape with event header
- .seatflow → full JSON project file for re-importing

## Ad Monetization
Search for `AD PLACEHOLDER` or `AD INTEGRATION POINT` in `pages/index.js`
to see exactly where to insert Google AdSense or a rewarded video SDK.
